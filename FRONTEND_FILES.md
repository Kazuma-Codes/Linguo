# Frontend — File-by-File Guide (`frontend/`)

> Stack: Next.js 14.2.25 App Router + React 18 + TypeScript strict + Zustand 5 + Tailwind 3.4.1 + PostCSS.
> Path alias: `@/* → ./src/*`. Entry: `src/app/layout.tsx → page.tsx`.
> Total hand-written files: ~42 (8 root configs + 34 src). Generated (`node_modules/`, `.next/`) summarized at bottom.

```
frontend/
├── package.json, package-lock.json, next.config.mjs, tailwind.config.ts,
│   tsconfig.json, postcss.config.mjs, .eslintrc.json, next-env.d.ts,
│   .env.example, .env.local, README.md, public/auth-art.png
└── src/
    ├── config.ts, types/global.d.ts
    ├── store/useAuthStore.ts, useChatStore.ts, useThemeStore.ts
    ├── lib/api.ts, languages.ts, avatarPresets.ts, icons.tsx
    ├── app/layout.tsx, page.tsx, chat/[roomId]/page.tsx, globals.css,
    │   favicon.ico, fonts/GeistVF.woff, GeistMonoVF.woff
    └── components/
        ├── auth/AuthScreen.tsx
        ├── chat/MergedMessageBubble.tsx, MergedComposer.tsx,
        │   ChatDraftPreview.tsx, CulturalFootnotes.tsx, RoomInfoDrawer.tsx
        ├── common/MergedAvatar.tsx, AvatarCropper.tsx, LogoutConfirmModal.tsx
        ├── contacts/ContactsTab.tsx, AddContactModal.tsx
        ├── groups/GroupsTab.tsx, CreateGroupModal.tsx
        ├── profile/ProfileModal.tsx, EditAvatarModal.tsx, UserDetailPopup.tsx
        ├── search/SearchOverlay.tsx
        └── settings/SettingsTab.tsx
```

Flow: `config.ts → lib/api.ts → page.tsx / chat/[roomId]/page.tsx`; `config.ts → store/useChatStore.ts (WS) → MergedComposer / ChatDraftPreview / MergedMessageBubble`.

## 1. Root Configs / Env / Meta

### `frontend/package.json`
**Purpose:** App manifest + scripts + dependency list.
**Key:** `scripts: dev/build/start/lint/typecheck`; `deps: next 14.2.25, react 18, react-dom, zustand 5`; `devDeps: typescript, tailwindcss 3.4.1, postcss, eslint-config-next`.
**Connects to:** All `src/*` via `next dev/build`.

### `frontend/package-lock.json`
**Purpose:** Pinned dependency tree for reproducible installs.
**Key:** Lockfile, no hand edits.
**Connects to:** Generated from `package.json` by `npm install`.

### `frontend/next.config.mjs`
**Purpose:** Next hardening + headers.
**Key:** `poweredByHeader:false`; `securityHeaders[X-Content-Type-Options:nosniff, X-Frame-Options:DENY, Referrer-Policy, Permissions-Policy]` + `headers() → /(.*)`.
**Connects to:** Applies to all routes from `src/app/layout.tsx`.

### `frontend/tailwind.config.ts`
**Purpose:** Tailwind scan + CSS-var theming bridge.
**Key:** `content: src/pages|components|app/**/*`; `theme.extend.colors{background:foreground}` via vars.
**Connects to:** `src/app/globals.css`, all `className="bg-[var(--...)]"` components.

### `frontend/tsconfig.json`
**Purpose:** Strict TS + path alias.
**Key:** `jsx:preserve, strict:true, paths: @/* → ./src/*, include: next-env.d.ts/**/*.ts(x)`.
**Connects to:** All `@/config, @/store/*, @/lib/*, @/components/*` imports.

### `frontend/postcss.config.mjs`
**Purpose:** CSS pipeline.
**Key:** `tailwindcss:{}` plugin only.
**Connects to:** `tailwind.config.ts + globals.css`.

### `frontend/.eslintrc.json`
**Purpose:** Lint rules (extends next).
**Key:** `extends: next/core-web-vitals` (standard).
**Connects to:** `npm run lint`; all `src/**/*.tsx`.

### `frontend/next-env.d.ts`
**Purpose:** Next-generated TS refs (do not edit).
**Key:** `/// <reference types="next" />`, image types.
**Connects to:** Generated by `next dev`; included by `tsconfig.json`.

### `frontend/.env.example`
**Purpose:** Env contract for devs.
**Key:** `NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1, NEXT_PUBLIC_WS_URL=ws://localhost:8000, NEXT_PUBLIC_GOOGLE_CLIENT_ID=`.
**Connects to:** Read by `src/config.ts`; `src/app/page.tsx` reads Google ID for `AuthScreen`.

### `frontend/.env.local`
**Purpose:** Local overrides (actual values, gitignored pattern).
**Key:** Same keys as `.env.example` with real URLs/IDs.
**Connects to:** Overrides `.env.example` at `next dev` runtime.

### `frontend/README.md`
**Purpose:** Default Next `create-next-app` readme (not Mosaic-specific).
**Key:** Install/dev/build links.
**Connects to:** None specific.

### `frontend/tsconfig.tsbuildinfo`
**Purpose:** Incremental build cache (generated, do not edit).
**Key:** Binary-ish JSON timestamps.
**Connects to:** Produced by `tsc --incremental`.

### `frontend/public/auth-art.png`
**Purpose:** Editorial artwork shown on left side of login wall.
**Key:** Static image `/auth-art.png` + quote overlay.
**Connects to:** Used by `src/components/auth/AuthScreen.tsx`.

## 2. `src/config.ts` + `src/types/`

### `src/config.ts`
**Purpose:** Central URL normalizer, single source of truth.
**Key:** `API_BASE_URL` (ensures `/api/v1` suffix), `WS_BASE_URL` (trim trailing `/`).

**Connects to:** `src/app/layout.tsx` `import './globals.css'`.

## 3. `src/store/` — Zustand (3 files)

### `src/store/useAuthStore.ts`
**Purpose:** Token + user persistence.
**Key:** `interface User{id,email,preferred_language,username?,avatar_url?,about?,phone?}`; `AuthState{token,user,hasHydrated,setAuth,updatePreferredLanguage,updateUserProfile,logout,setHasHydrated}` via `persist + onRehydrateStorage`, key `auth-storage` in `localStorage`.
**Connects to:** `src/lib/api.ts` (auto-`logout()` on 401/403), `src/store/useChatStore.ts` (logout on WS 1008/max-reconnect), `src/app/page.tsx`, `src/app/chat/[roomId]/page.tsx`.

### `src/store/useChatStore.ts` (383 lines, realtime core)
**Purpose:** WS lifecycle + `messages/drafts/replyTo/typingUsers/isConnected`.
**Key:** `Message{id,sender_email,original_text,translated_text,translations,detected_lang,cultural_footnotes,reply_to_id,attachment_*,delivery_status,is_me,status:draft|final}`; `IncomingWSMessage`; `connect(roomId,token,myEmail) → ws://.../api/v1/ws/chat/{roomId}?token=` + `ping(25s)` + `reconnect exp-backoff max6`; handlers `pong/typing/read_ack/message_deleted/draft_ready/message_finalized`; actions `sendDraft/confirmDraft/sendMessage(=send_draft)/sendTyping/sendReadAck/deleteMessage/disconnect/setInitialMessages`.
**Connects to:** `@/config WS_BASE_URL`, `@/store/useAuthStore`; used by `MergedComposer, ChatDraftPreview, MergedMessageBubble`, both pages.

### `src/store/useThemeStore.ts`
**Purpose:** Light/dark theme.
**Key:** `ThemeMode light|dark`, `ThemeState{theme,setTheme,toggleTheme}`, persisted `mosaic-theme`, toggles `documentElement[data-theme/.dark]`.
**Connects to:** `src/app/page.tsx`, `chat/[roomId]/page.tsx`, `AuthScreen, ProfileModal, SettingsTab`.
